# Presentation backup screenshots

Full-page captures of every critical stage of the Ben Peretz pilot presentation,
generated by `apps/web/e2e/presentation.spec.ts`. Use these as a fallback if
on-site connectivity fails — the entire pitch can be delivered from these images.

Regenerate after UI changes:

```bash
pnpm --filter @aion/web build
cd apps/web && DEMO_MODE=true pnpm exec playwright test presentation
```
